# 日本国内における「無リスク・低ボラティリティ資産」の候補：2026年版

## ゼロリスク資産の条件は基準価額が安定していること

[生存確率を上げる戦略：無リスク資産を持つ](zero_risk.md) では、ポートフォリオに無リスク資産を組み入れ、運用初期に優先的に活用することで、長期的な生存確率を高める効果を検証しました。本稿では、その具体的な実践として、日本の投資家が実際に購入できる具体的な銘柄を比較・選定するためのガイドを提示します。

「無リスク（あるいはそれに準ずる低ボラティリティ）資産」と呼べるものの条件は、「市場の混乱時であっても基準価額（価格）の変動が小さいこと」です。平時の利回りが高くても、市場の急落時に株式と一緒に下落してしまう資産は、ポートフォリオの安全な資産の置き場所としては機能しません。

!!! abstract "重要なポイント"
    * **無リスク資産の具体的な選定ガイド:** [無リスク資産の保有効果](zero_risk.md)を背景に、実運用で活用できる具体的な銘柄を提示する。
    * **市場の混乱時でも基準価額が安定している資産を厳選:** 市場の急落時であっても価格変動が小さいことを条件とする。
    * **米国短期債ETFと外貨建てMMFが選択肢:** 高金利環境を活かし、米ドルの信用力を背景とした運用が合理的。

本稿では、信用リスクや価格変動リスクを抑えた上で、現在の高金利環境を活かして**「年利2%以上」**のインカムゲインを確保できる資産を厳選しました。結果として、為替リスクを許容しつつ米国政府の信用力を背景とした「米国短期・超短期債ETF」および、外貨ベースで元本が保全される「外貨建てMMF」が、現在の日本の投資家にとって合理的な安定資産の選択肢となります。

## 資産の解説と運用戦略

### 1. 米国超短期債・短期債ETF（金利変動リスクの抑制）

米国超短期債（Ultra-Short Term）や短期債（Short-Term）のETFは、満期までの期間が短い米国の債券（主に国債や格付けの高い社債）をパッケージにした上場投資信託です。債券は「満期までの期間（デュレーション）」が短いほど、市場金利が変動した際の価格の変動が小さくなります。

数字は2026年5月のものです。

*   **[133A（グローバルX 超短期米国債 ETF）](https://globalxetfs.co.jp/funds/133A/index.html)**: SGOVと同様に残存期間1〜3ヶ月の米国T-Billを対象とするが、東証に上場しているため**日本円で直接取引できる**点が特徴です。ドルに両替する為替手数料や手間を省きつつ、約3.76%の利回りを確保できます。
*   **[VGSH](https://investor.vanguard.com/investment-products/etfs/profile/vgsh)**: バンガード社が提供する残存期間1〜3年の短期国債ETF。利回りは約3.84%、経費率は0.03%と低コストです。SGOVよりわずかに価格変動がありますが、平時のボラティリティは低く抑えられています。
*   **[SGOV](https://www.ishares.com/us/products/314116/ishares-0-3-month-treasury-bond-etf) および [SHV](https://www.ishares.com/us/products/239466/ishares-short-treasury-bond-etf)**: 残存期間が1年未満（SGOVに至っては3ヶ月未満）の米国債のみで構成されます。基準価額の変動が小さい一方で、銀行預金を上回るインカムを生み出します。

### 2. 外貨建てMMF（待機資金の活用）

外貨建てMMF（マネー・マーケット・ファンド）は、投資家から集めた外貨を、格付けの高い短期の公社債などで運用する投資信託の一種です。銀行の外貨預金と似ていますが、証券会社を通じて取引される「投資信託」である点が大きな違いです。

外貨ベースでの「1口＝1セント等」の基準価額が固定されており、外貨のまま保有している限り元本割れが原則起こらない仕組みになっています。証券口座内で米国株の売却代金や配当金をプールしておく「待機資金の置き場所」として適しており、SBI証券のブラックロック（約3.18%）や楽天証券の楽天・米ドルMMF（約3.17%）などは、株式買付時の余力として即座に充当できる流動性の高さが特徴です。詳細な取扱銘柄や最新の利回りは、[SBI証券](https://site0.sbisec.co.jp/marble/fund/fmmf/servicelist.do?)や[楽天証券](https://www.rakuten-sec.co.jp/web/rfund/find/foreign_mmf/yield/)の公式サイトをご確認ください。

## Appendix：検討対象から除外した資産一覧

初期の調査では以下の資産も候補に挙がっていましたが、本稿の優先要件である「基準価額の安定性」または「想定利回り2%以上」のいずれかを満たさないため、表から除外しています。

| 除外した資産分類 | 該当する具体的な銘柄例 | 除外した主な理由（リスク・利回り不足など） |
| :--- | :--- | :--- |
| **ハイイールド社債 ETF** | HYG, JNK など | 平時のボラティリティは低く見えますが、**「信用リスク（倒産リスク）」**が含まれており、市場の混乱時には株式に匹敵する下落を起こすため、安定資産には不適格です。 |
| **国内定期預金・個人向け国債** | ネット銀行定期、変動10年国債など | 元本保証という条件は満たすものの、直近の利回りが低い水準にとどまり、**「利回り2%以上」という要件を満たさない**ため除外しました。 |
| **J-REIT / インフラファンド** | 8985 (ジャパン・ホテル) など | 実物資産を裏付けとしているため、株式市場の変動に連動して**基準価額が上下する（ボラティリティが高い）**ため除外しました。 |
| **高配当株ETF / 優先証券ETF** | 1494, PFF など | 利回りは高いものの、本質的に株式（またはそれに準ずるハイブリッド証券）であり、相場急落時の**価格下落リスクが無視できない**ため除外しました。 |
| **カバードコールETF** | 2865 (グローバルX NASDAQ100) など | オプション戦略により高い利回りを実現しますが、原資産の価格下落リスクをそのまま受けるため、**基準価額の安定性が担保されない**ことから除外しました。 |
| **国内・円建て MRF/MMF** | 証券口座の円待機資金 | 基準価額は安定していますが、利回りが**低く、2%の基準に満たない**ため除外しました。 |
